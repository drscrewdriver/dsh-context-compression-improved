## Что это такое

Долгоживущие задачи агентов накапливают большой объём вывода инструментов. Этот плагин сообщества добавляет выбираемые и проверяемые политики сокращения контекста результатов инструментов без изменения ядра DeepSeek Harness:

- **Fresh** предварительно сжимает новый ставший чрезмерным сегмент результата инструмента до того, как модель его получит.
- **Aggregate** повторно предварительно сжимает свежий материал, если тот продолжает выходить за свой бюджет.
- **History / micro-compact** заменяет подходящие старые результаты инструментов, сохраняя недавний рабочий контекст.
- **TailTrim** — необязательный путь сокращения хвоста, доступный только в режиме Custom.
- **Native** сохраняет характерное для Harness усечение начала/середины/хвоста как отдельный явный профиль.
- **Скелет кода (новый, ортогональный гейт)** — см. ниже.

Каждое решение фиксируется: этап, редьюсер, триггер, причина пропуска и точные количества токенов, где они доступны.

## Гейт скелетов кода (новый)

Когда гейт включён, чрезмерный **свежий результат инструмента с исходным кодом** (например, большой `read_file`) сначала пытается пройти редукцию до скелета: импорты и объявления типов/функций/классов сохраняются, тела функций опускаются с маркером, а строки с ошибками внутри опущенных тел сохраняются. Если скелет невозможно построить или проверить, результат откатывается к исходной обрезке начала — гейт никогда не может сделать контекст хуже.

Свойства:

- **Ортогональность**: независим от выбранного профиля (`balanced`, `savings`, `cache-strict`, `adaptive`, `custom`, `off`, `native`). Гейт получают все профили.
- **По умолчанию выключен**: `codeSkeleton: { enabled: false }`, пока вы его не включите.
- **Зависит от измерения**: требует точного токенизатора DeepSeek; без него плагин работает по принципу fail-open.
- **Заморозка на сессию**: как и все настройки селектора, изменения затрагивают только новые наблюдаемые сессии.
- **Строгий разбор**: `codeSkeleton` должен быть в точности `{ enabled: boolean }`; некорректные значения вызывают ошибку на стороне рантайма и отображаются в браузерном UI как нечитаемые.

## Установка

**Рекомендуется: установка из npm.** Одна версия обслуживает все поддерживаемые линейки Harness — `latest` несёт полный перечень из 15 rc (0.1.0-rc.2 → 0.2.0-rc.2); рантайм сам выбирает ветки кода для своей линейки.

```sh
dsh plugin --profile web add dsh-context-compression-improved@latest
dsh --profile web --dump-config
```

Из исходников (альтернатива — внутренние имена пакетов намеренно остаются апстримовскими):

```sh
git clone https://github.com/drscrewdriver/dsh-context-compression-improved.git
cd dsh-context-compression-improved
pnpm install --frozen-lockfile
pnpm build
```

Затем упакуйте пакет селектора и добавьте его в профиль Harness — полное пошаговое руководство, включая проверку и удаление, приведено в [руководстве по установке](docs/installation.md).

## Разработка

```sh
pnpm install --frozen-lockfile
pnpm lint          # ESLint baseline (also enforced in CI)
pnpm typecheck     # runtime + selector + tests tsc, plus the bundle step
pnpm test          # full vitest suite
pnpm test:watch    # TDD loop: write the failing regression first, then make it pass
pnpm build
pnpm verify:release
```

Вклад следует апстрим-дисциплине: сначала добавляется падающая регрессия, все производственные изменения остаются в этом репозитории, а свидетельства «triggered», «enabled but skipped» и fail-open объясняются раздельно. См. [CONTRIBUTING.md](CONTRIBUTING.md).

## Совместимость

- Собрано и протестировано против официальных релизов DeepSeek Harness; peers перечисляют полный список поддержки (`0.1.0-rc.2` → `0.2.0-rc.2`, шесть линеек), и плагин использует только публичные API плагинов и профилей. Список генерируется `scripts/sync-hosts.mjs` из `scripts/hosts.mjs` в управляемый блок выше.
- Требуются Node `^22.19.0 || >=24` и pnpm `11.7.0`.
- Плагин использует только публичные API расширений Harness и не изменяет код ядра Harness. Неофициальный проект сообщества, не связан с DeepSeek и не одобрен им.
