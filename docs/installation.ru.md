# Установка dsh-context-compression-improved

> [English](installation.md) · [中文](installation.zh.md) · [日本語](installation.ja.md) · [한국어](installation.ko.md) · [Français](installation.fr.md) · [Deutsch](installation.de.md) · [Italiano](installation.it.md) · [Русский](installation.ru.md) · [Español](installation.es.md)

Это руководство описывает установку форка из исходников. Форк также опубликован в npm как
`dsh-context-compression-improved` под dist-tag `dsh-0.1.5`; имя пакета намеренно совпадает
с апстримовским. Рантайм, который раньше был отдельным вторым пакетом, теперь входит в его
состав, поэтому одна установка приносит весь стек целиком.

## Предварительные требования

- Node `^22.19.0 || >=24` и pnpm `11.7.0` (`corepack enable` берёт зафиксированную версию из поля `packageManager`).
- Установка DeepSeek Harness, совместимая с диапазоном peers `0.1.1-rc.2` (проверено против официального релиза `dsh-v0.1.2-alpha.5`).
- Маршрут модели DeepSeek. Сжатие с потерями — включая гейт скелетов кода — принимает решения на символьной основе, поэтому требование к маршруту со встроенным токенизатором больше не действует; если встроенный токенизатор есть, его точные подсчёты записываются как телеметрия, а остальные маршруты работают по принципу fail-open и сохраняют исходные результаты инструментов.
- Git.

## 1. Сборка из исходников

```sh
git clone https://github.com/drscrewdriver/dsh-context-compression-improved.git
cd dsh-context-compression-improved
pnpm install --frozen-lockfile
pnpm build
```

`pnpm build` бандлит обе библиотечные грани каждого пакета (`tsdown`). Если хотите прогнать полный набор тестов на своей машине до установки, сначала выполните `pnpm test`.

## 2. Упаковка входного пакета Bundle

Пакет селектора — единственный вход Bundle; рантайм идёт с ним как зависимость точной версии:

```sh
cd packages/selector
pnpm pack
# → dsh-context-compression-improved-0.1.0.tgz
cd ../..
```

`pnpm pack` прогоняет бандл через хук `prepack`, поэтому tarball всегда соответствует вашему checkout.

## 3. Добавление в профиль Harness

Пакет селектора объявляет поле манифеста Bundle харнесса `dsh.bundle.patch`, поэтому `dsh plugin add` — это стандартный путь установки Bundle вне дерева:

```sh
dsh plugin --profile web add packages/selector/dsh-context-compression-improved-0.1.0.tgz
dsh --profile web --dump-config
```

После установки перезапустите выбранный профиль. В дампе конфигурации Bundle селектора должен значиться как активный. **Не** устанавливайте и не подключайте пакеты селектора и рантайма по отдельности — рантайм устанавливается автоматически.

## 4. Включение гейта скелетов кода

Откройте настройки DeepSeek Harness → **Context compression selector**:

1. Выберите профиль сжатия (гейт ортогонален всем).
2. При необходимости отрегулируйте уровень срабатывания Auto Compact (50–90%, по умолчанию 80%).
3. Установите **Code skeleton compression** в **On**. Переключатель сохраняет значение при каждом изменении.

Как и все настройки селектора, значение замораживается, когда сессия впервые его наблюдает, — гейт затрагивает только новые наблюдаемые сессии и никогда не меняет уже идущую задачу.

## 5. Необязательно: рекомендательный advisor релевантности

Плагин может вести статистику того, насколько ещё релевантна история сессии, — только в качестве совета, он ничего не решает и ничего не блокирует. По умолчанию выключен; включается редактированием секции `presetOptions` в настройках сжатия контекста (настройки в JSON, карточки в UI на этом этапе нет):

```json
"presetOptions": {
  "advisorMode": "host",
  "advisorRefreshTurns": 8,
  "advisorScoreThreshold": 0.35,
  "advisorSampleLimit": 16,
  "advisorMinTokens": 250,
  "advisorTimeoutMs": 8000
}
```

`advisorMode: "host"` вызывает сервис `llm` харнесса; `"direct"` повторно использует endpoint
`estimatorBaseUrl` / `estimatorApiKey` / `estimatorModel` эстиматора. На каждой границе хода
advisor (1) резюмирует текущую задачу по последнему событию `todo/write`, (2) инкрементально
оценивает исторические результаты инструментов на релевантность «содержимое и комментарии» и
(3) записывает показатель префиксного затухания. Результаты появляются как записи аудита
`advisor-outcome`, а при включённом флаге развёртывания `advisorReportRoute: true` — ещё и
через доступную только для чтения HTTP-маршрут `GET .../advisor-report?sessionId=`. Ни на
какую редукцию, которая должна примениться, то, что сообщает advisor, повлиять не может:
не подавить её, не задержать и не переписать.

## 6. Обновление или удаление

```sh
# update: pull, rebuild, repack, and add the new tarball again
git pull && pnpm install --frozen-lockfile && pnpm build
cd packages/selector && pnpm pack && cd ../..
dsh plugin --profile web add packages/selector/dsh-context-compression-improved-0.1.0.tgz

# remove
dsh plugin --profile web remove dsh-context-compression-improved
```

## Устранение неполадок

- **Bundle не активен в дампе**: перезапустите профиль; убедитесь, что вы добавили входной пакет селектора (а не рантайм) и что версия Harness попадает в совместимый диапазон peers.
- **Результаты инструментов никогда не сжимаются до скелета**: гейт по умолчанию выключен; проверьте переключатель. Сжатие применяется только к свежим, чрезмерным результатам инструментов с исходным кодом (решения принимаются на символьной основе; требования к маршруту с точным токенизатором нет), и каждый пропуск фиксируется с указанием причины в журнале аудита.
- **Переключатель отображается как нечитаемый**: сохранённая секция `codeSkeleton` не прошла строгий браузерный декодер (она должна быть в точности `{ enabled: boolean }`). Удаление некорректной секции возвращает значения по умолчанию.
- **Обновление падает на шаге апгрейда**: плагин следует семантике npm-пакетов; если ваша сборка Harness отказывает в обновлении с tarball на tarball, сначала удалите старую версию.
